# Мой уход — Panasonic EH-SR90 · PWA v2.0

Русскоязычный планировщик на основе выбранного недельного ухода. Это независимое PWA, не приложение Panasonic.

## Что улучшено во второй версии
- Структура ближе к логике with Panasonic Beauty: «Сегодня», «План», «История», «Настройки».
- Отдельный экран сегодняшней процедуры с этапами CLEAN, MOIST, специальным режимом и завершающим уходом.
- Пошаговый экран с таймером 2/3/6 минут.
- Редактируемый недельный план с проверкой частоты: RF × EMS LIFT + RF PUMP суммарно не более 3/неделю, с минимум одним днём перерыва между этими RF-сеансами; EYE CARE не более 3/неделю, с минимум одним днём перерыва между EYE CARE. Не совмещать два специальных режима в один день.
- Календарь отметок, заметки о реакции кожи, график регулярности и дата-цель.
- Экспорт повторяющихся событий .ics для системного календаря; экспорт и импорт резервной копии.
- Исправлены сохранение даты в локальном времени, таймер при переключении экранов/дней, повторяющиеся календарные напоминания и проверка разрешения уведомлений.
- Миграция отметок/заметок и времени из версии v1, если она была установлена с тем же origin.

## Установка с Windows через GitHub Pages
1. Распакуйте архив.
2. Создайте бесплатный репозиторий на https://github.com/ (Public).
3. Загрузите все файлы и папку (в данном проекте файлы лежат в корне) в корень репозитория.
4. Откройте Settings → Pages → Build and deployment → Deploy from a branch; Branch `main`, Folder `/ (root)` → Save.
5. После публикации откройте адрес вида `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/` в Safari на iPhone.
6. Safari → Поделиться → На экран «Домой» → Добавить. Откройте приложение один раз онлайн для установки кэша.

## Напоминания
- В приложении включаются уведомления браузера. Они могут сработать только пока приложение открыто и iOS не приостановила страницу. Это не надёжная замена системному планировщику.
- Для фоновых/закрытых состояний нажмите «Добавить еженедельные напоминания в календарь (.ics)», откройте файл на iPhone и импортируйте его в Apple Calendar. В каждом дне заголовок и текст напоминания сообщают запланированный режим. Время по умолчанию 21:00.
- При изменении времени или недельного плана экспортируйте файл .ics повторно и замените старые события в календаре, чтобы не получить дубли.

## Важные ограничения
- PWA не подключается к EH-SR90 по Bluetooth и не считывает фактическое включение прибора. Процедуры отмечаются вручную.
- Здесь нет AI-сканирования кожи, диагностики, автоматических оценок кожи или видеоуроков Panasonic. Для движения прибора и техники используйте официальную инструкцию/видео Panasonic.
- Программа по умолчанию: Пн RF × EMS LIFT, Ср EYE CARE, Пт RF PUMP, Вс EYE CARE; Вт/Чт/Сб — восстановление.
- Для RF × EMS LIFT указан Panasonic EH-4R06. Для RF PUMP — сыворотка/эмульсия по руководству Panasonic. EYE CARE: MT Metatron B5 Contour только если конкретная упаковка разрешает область вокруг глаз; не обрабатывать веки.
- Общий порядок в день со специальным режимом: CLEAN → MOIST → специальный режим. В день восстановления MOIST — последний режим прибора.
- Перед применением соблюдайте противопоказания и полную инструкцию EH-SR90. При раздражении/боли/стойком покраснении остановите процедуру.

## Приватность
Данные плана, отметки, заметки и цель остаются в localStorage браузера на устройстве. Сервер/аккаунт для работы приложения не нужен. Резервную копию можно выгрузить JSON-файлом.
