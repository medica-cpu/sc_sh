# Мой уход — Panasonic EH-SR90 · версия 15

## Что входит

- Ежедневный комплимент из набора более чем 100 фраз.
- Недельный график с выбором дня; повторное нажатие на выбранную дату скрывает или раскрывает подробный план.
- Пошаговый экран с крупным таймером, кнопками «Назад» и «Далее» под таймером и центральной кнопкой старта ниже.
- Короткий звуковой сигнал в конце таймера; его можно отключить в настройках.
- План недели с проверкой частоты RF × EMS LIFT / RF PUMP и EYE CARE.
- История с календарём, отметками процедур, заметками и графиком регулярности.
- Раздел «Техника»: карусель из пяти видео, фото-схемы по режимам и отдельная карусель «Очистка» из двух слайдов.
- Настройки времени напоминаний, переключатели двух видов напоминаний, редактирование названий используемых средств, цель и экспорт/импорт данных.
- Локальные изображения инструкций кэшируются и доступны офлайн после первой загрузки.

## Напоминания и пользовательское время

В настройках открой «Напоминания» и выбери любое удобное время в поле «Время напоминания». Изменение сохраняется на устройстве сразу после выбора.

Есть два типа напоминаний: о начале ежедневного ухода и о специальных процедурах. Приложение проверяет время, пока открыто. Обычная PWA не может гарантированно запускать уведомления по расписанию, когда Safari/iOS полностью приостановила приложение. Для надёжных уведомлений в закрытом состоянии нажми «Скачать напоминания для календаря (.ics)» и импортируй файл в Apple Calendar; после изменения времени или расписания экспортируй файл заново.

## Установка или обновление через GitHub Pages (Windows + iPhone)

1. Распакуй архив на компьютере Windows.
2. Открой прежний GitHub-репозиторий, который публикует приложение через GitHub Pages.
3. Замени все старые файлы новыми файлами и папкой `assets` из архива. Сохрани структуру папок.
4. Сделай Commit changes и дождись окончания публикации GitHub Pages.
5. На iPhone полностью закрой установленное PWA, снова открой его с главного экрана и подожди обновления service worker. Если старая версия осталась, открой адрес сайта в Safari, обнови страницу и снова запусти PWA.

**Важно:** сохрани прежний адрес GitHub Pages. Приложение использует прежний ключ локального хранилища `ehsr90-planner-v2`, поэтому расписание, отметки, заметки и настройки должны остаться в этом же браузере на устройстве. Для страховки перед обновлением можно экспортировать данные в разделе «Настройки».

## Видео и фотосхемы

- RF × EMS LIFT и RF PUMP используют один предоставленный пользователем ролик YouTube и одну последовательность четырёх схем: `rf-1.png`, `rf-2.png`, `rf-3.png`, `rf-4.png` (в том порядке, который был указан пользователем).
- EYE CARE использует предоставленную схему `eye-care.jpg`.
- Видео EYE CARE, CLEAN и MOIST открываются по ссылкам YouTube, добавленным пользователем.
- Схемы CLEAN и MOIST загружаются с сайта Panasonic; для их просмотра нужен интернет. Если изображение на сайте Panasonic переместится или будет недоступно, открой официальную инструкцию по ссылке внутри приложения.
- Раздел «Очистка» содержит два пользовательских слайда: промывание головки/кольца с русскими пояснениями и просушивание/хранение.

## Важные ограничения

Это независимый PWA-планировщик, не приложение Panasonic и не медицинское устройство. Он не подключается к EH-SR90 и не заменяет официальную инструкцию. Время движения по стрелке — не длительность всего режима: например, RF × EMS LIFT и RF PUMP имеют общую длительность около 6 минут; таймер показывает именно общую длительность соответствующего этапа.

Перед процедурой проверяй рекомендации и противопоказания в руководстве EH-SR90. При боли, раздражении или стойком покраснении прекращай использование и следуй руководству производителя.

## Конфиденциальность

Расписание, отметки, заметки, пользовательские названия косметики и параметры хранятся локально в `localStorage` браузера на этом устройстве. Экспорт истории создаёт JSON-файл на устройстве. Данные не отправляются на сервер приложения.


## Исправление изображений (v15)
Все подготовленные схемы и иллюстрации теперь встроены в `media.js` как локальные данные. Приложение больше не зависит от путей к папке `assets` для показа этих изображений и не загружает схемы CLEAN/MOIST с внешнего сайта Panasonic. `media.js` должен быть загружен вместе с `index.html`, `app.js`, `styles.css` и `sw.js`. Папка `assets` оставлена в архиве как исходные файлы изображений. Service Worker обновлён до `ehsr90-pwa-v15`, поэтому после публикации он должен заменить старый кеш.

Для обновления GitHub Pages загрузите все файлы из архива с сохранением папки `assets`. После публикации закройте приложение на iPhone полностью, откройте сайт один раз в Safari с интернетом и затем снова запустите иконку на главном экране.


## Исправление загрузки иллюстраций (v15)
В этой версии все схемы и подготовленные изображения встроены в `media.js` как локальные данные. Благодаря этому отображение иллюстраций не зависит от GitHub Pages subpath и путей в папке `assets`. `media.js` подключается перед `app.js`; оба файла должны быть загружены в корень репозитория вместе с `index.html`, `styles.css`, `sw.js`, `manifest.webmanifest` и иконками. Версия Service Worker и query-параметры ресурсов обновлены до v15, чтобы браузер заменил старый кеш.

После Commit changes дождитесь завершения GitHub Pages deployment. На iPhone закройте установленную PWA, откройте адрес сайта в Safari с интернетом, обновите страницу, затем снова запустите приложение с иконки. Если показывается старая версия, в Safari откройте сайт ещё раз после закрытия PWA и подождите завершения обновления Service Worker.


## Исправление модальных окон (v15)
Модальные окна пошаговой процедуры, фотосхем и очистки теперь закрываются при переходе на другую вкладку. Одновременно может быть открыто только одно такое окно. Поэтому панель навигации «Назад / Далее» пошагового режима показывается только внутри процедуры, открытой из вкладки «Сегодня», а окно «Уход за прибором» не остаётся поверх других вкладок.
