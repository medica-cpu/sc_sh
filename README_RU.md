# Мой уход — Panasonic EH-SR90 · версия 16

## Что входит

- Ежедневный комплимент из набора более чем 100 фраз.
- Недельный план и пошаговое сопровождение процедур.
- Таймеры для этапов и короткий звуковой сигнал по окончании (можно отключить в настройках).
- Проверка частоты специальных режимов при редактировании плана.
- История с календарём, заметками и графиком регулярности за 7 дней. График показывает процент по каждому дню, учитывает частично выполненные этапы и выводит суммарный процент.
- Вкладка «Техника»: пять видео, фотоинструкции для режимов, отдельная кнопка «Очистка» с пятью слайдами.
- Раздел очистки: слайды «Промой головку», «Промой кольцо», «Протри головку», «Просуши все детали», «Готово!».
- Настройки напоминаний, произвольное время, переключатели типов напоминаний, редактирование названий косметических средств, цели, экспорт и импорт данных.
- Локальные изображения очистки добавлены в папку `assets` и предварительно кэшируются Service Worker.

## Исправление диалоговых окон

В v16 исправлена причина, из-за которой модальные окна отображались как постоянные блоки под любой вкладкой: в CSS авторские `display:grid`/`display:flex` перекрывали стандартное скрытие закрытого элемента `<dialog>`. Теперь все закрытые диалоги принудительно скрыты. Блок с кнопками «Назад / Далее» показывается только при открытом пошаговом режиме из вкладки «Сегодня». Карусель очистки открывается только из кнопки «Очистка» во вкладке «Техника»; постоянного блока «Уход за прибором» на вкладках больше нет.

## История и процент выполнения

Процент за каждый из последних семи дней рассчитывается как число отмеченных этапов, делённое на все этапы по плану этого дня. Например, 2 выполненных этапа из 4 дают 50%. Полностью завершённые дни, отмеченные в прежней версии только общей галочкой, учитываются как 100%.

## Напоминания

В настройках выбери желаемое время в поле «Время напоминания». Значение сохраняется локально. Для надёжных уведомлений, когда PWA закрыто, экспортируй `.ics` и импортируй события в Apple Calendar. После изменения времени или недельного расписания создай и импортируй новый файл; уже импортированные события календаря автоматически не меняются.

## Обновление через GitHub Pages (Windows + iPhone)

1. Распакуй архив на компьютере Windows.
2. В прежнем GitHub-репозитории замени все файлы из архива, сохранив структуру папки `assets`.
3. Сделай Commit changes и дождись окончания публикации GitHub Pages.
4. На iPhone открой адрес GitHub Pages в Safari, обнови страницу и дождись загрузки новой версии. Затем полностью закрой PWA и запусти иконку приложения снова.
5. Сохрани прежний адрес GitHub Pages: приложение использует прежний ключ `ehsr90-planner-v2`, поэтому история, отметки и настройки должны сохраниться.

Перед обновлением для страховки можно экспортировать резервную копию во вкладке «Настройки».

## Ограничения

Это независимый планировщик, не приложение Panasonic и не медицинское устройство. Он не подключается к EH-SR90 и не заменяет руководство производителя. Видео YouTube требуют подключения к интернету; локальные изображения после первой загрузки доступны офлайн.

## Конфиденциальность

Расписание, отметки, заметки, пользовательские названия средств и настройки хранятся в `localStorage` на этом устройстве. Данные не отправляются на сервер приложения.
